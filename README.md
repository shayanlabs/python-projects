## 🔧 How every project is made

1. **Build** it step by step from a build sheet. **I write every line of code.** AI is my tutor and gives one-line hints, never the code.
2. **Run** it after every step.
3. **Ship** it here when it works, with a sample run in its README.

## ▶️ Run a project

Plain Python 3, nothing to install:

```bash
python3 01-match-scorecard/match_scorecard.py
```
